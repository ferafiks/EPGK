# Zasoby na EPGK

## Instalacja Pythona

### Dla Windowsa
[Link do pobrania](https://www.python.org/downloads/).

### Dla Linuxa
Wyszukajcie nazwe paczki dla waszej dystrybucji i zainstalujcie przez terminal.

## Jak włączyć skrypt Pythona?
1. Otwórz folder z skryptem
2. Naciśnij prawym przyciskiem na puste miejsce i kliknij `Otwórz w terminalu`
3. Po otworzeniu okienka terminala, uruchom komende `python NAZWA_PLIKU`. Terminal dokończy pisać nazwe pliku za ciebie gdy naciśniesz tab (czasem dwukrotnie).

## Edytowanie skryptów Pythona
Teoretycznie można je edytować nawet w notatniku, ale o wiele wygodniej jest kożystać z code-editora. Osobiście polecam [Visual Studio Code](https://code.visualstudio.com/) (inne niż `Visual Studio`).

Dla Linuxa: wyszukajcie nazwe paczki dla waszej dystrybucji i zainstalujcie przez terminal. VSCode jest też dostępny nieoficjalnie jako flatpak, ale chyba lepiej jest używać natywnej wersji.

Po zainstalowaniu, można wejść w `File/Open Folder` i otworzyć folder zawierający skrypty. Polecam stworzenie sobie folderu do zajęć i trzymania w nim wszystkich rzeczy z labów w osobnych podfolderach.

Po otworzeniu skryptu, powinien wyświetlić się komunikat w prawym dolnym rogu, aby zainstalować wtyczkę do Pythona. Kliknij go i zainstaluj.

### Uruchamianie skryptów w Visual Studio Code

W prawym górnym rogu jest ikonka strzałeczki, która uruchomi twój otwarty skrypt. Za pierwszym razem trzeba się przeklikać przez menu aż dojdzie się do opcji by odpalić otwarty skrypt.

---

VSCode posiada też terminal, który można włączyć klikając ikonke panelu dolnego w prawym górnym rogu. Przez niego można uruchomić skrypt podobnie jak to robiliśmy na początku tego poradnika.
